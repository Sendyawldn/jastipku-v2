# Jastipku UI Design System & Intent

## Anchor
"Premium Secure Courier & Vault": Inspired by high-end secure logistics and digital vaults (e.g., Chrono24, DHL Premium), adopting a dark, elegant aesthetic with glassmorphism to communicate absolute security and exclusivity.

## Tokens
- **Typography**: 
  - *Display/Headers*: Elegant geometric sans-serif (Outfit or Plus Jakarta Sans) for strong, modern headers.
  - *Body*: Clean readable sans-serif (Inter).
  - *Mono*: JetBrains Mono for data points.
- **Colors**:
  - *Primary Background*: Deep Midnight Blue/Black (`#0A0A0A` to `#0B132B`).
  - *Surface*: Translucent glass panels (`rgba(255, 255, 255, 0.05)`) with subtle borders (`rgba(255, 255, 255, 0.1)`).
  - *Accent*: Vibrant Cyan/Teal (`#00F0FF`) and Champagne Gold (`#FFD700`) for primary actions and glowing highlights.
- **Spacing**: 8px base unit (8, 16, 24, 32, 64). Generous padding for a premium, uncrowded feel.
- **Radius**: Large rounded corners (16px to 24px) for cards to contrast with the previous sharp edges.
- **Shadow**: Deep, soft colored glowing shadows for interactive elements.
- **Motion**: Fluid, floating, and smooth easing (e.g., 0.4s ease-out).

## Constraints
- WCAG 2.2 AA Contrast floor.
- No pure white backgrounds on primary pages.
- Avoid cluttered tables without distinct visual hierarchy.
